# Security policy

This repository holds documentation and small scripts, no deployed service. If you find a security problem in a script, a workflow or a fixture, report it privately through [GitHub security advisories](https://github.com/mokevnin/dev-quality-gates/security/advisories/new) instead of a public issue.

A tool listed here that has a vulnerability is a different matter: open a [proposal](https://github.com/mokevnin/dev-quality-gates/issues/new/choose) with a link to the advisory.
